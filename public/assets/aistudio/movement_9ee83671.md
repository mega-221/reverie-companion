# Movement

<!-- chapter: 03-survival-and-combat | pages: 24-24 -->

On each of their turns, each combatant gets a movement action. On a movement
action, a character can elect to move in any direction for as much as their speed
allows. A character’s speed is calculated using the following formula:
Movement Speed
[ Athletics + GRT + REF ]
To find out how many tiles a character can travel in a single movement action,
compare their Movement Speed value to the information below:
0-1: 2 tiles
2-4: 3 tiles
5-9: 4 tiles
10+: 5 tiles
Tile conversion
Tiles can be directly translated into real measurements:
1 tile = 1.5m ~ 5 feet
For the sake of simplicity, this rulebook will only express combat distances in tiles.

# Reverie Companion

Reverie Companion is a Vite + React + TypeScript application for managing character sheets, parties, NPCs, combat, inventory, and the Reverie rules compendium.

## Development

```bash
npm install
npm run dev
npm run test
npm run lint
npm run build
```
